数据说明：资金流数值来源于东方财富公开行情接口（主力 / 超大单 / 大单 / 中单 / 小单净额），盘中按轮询间隔累积分时序列，日级历史用于趋势与基准计算。金额单位为人民币元，页面按 亿 / 万 缩写显示。
当东财实时行情拒绝当前出口 IP 时自动降级：清单改用新浪、净额改用腾讯「（外盘 − 内盘）× 100 × 现价」折算的当日累计主动净买入额（口径为全部主动买卖，含中小单，与主力口径不同，方向一致），顶部来源标签会标注降级状态。
指标口径：主力净流入 = 超大单 + 大单净额；净占比 = 主力净额 / 成交额；「较近 5 日均值差额」= 当日主力净额 − 前 5 个交易日主力净额均值。所有阈值可在「阈值规则」中调整。
风险提示：本平台仅用于资金流向的观察与研究，不构成任何投资建议。行情数据可能存在延迟或缺失，请以交易所披露为准。
